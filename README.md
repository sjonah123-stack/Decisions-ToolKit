# Decision Toolkit

A free, browser-based set of **eight decision-making frameworks** with a built-in recommender that matches your problem to the right tool. No account, no tracking, no server — everything runs locally in your browser and auto-saves to your device.

**[▶ Live demo]((https://sjonah123-stack.github.io/Decisions-ToolKit/))**

## Frameworks

| Tool | Use it when you're… |
|------|---------------------|
| **Start here** (recommender) | Not sure which framework fits — describe your decision and get matched. |
| **Weighted Matrix** | Comparing options across several criteria that matter differently (vendors, candidates, products). |
| **RICE / ICE** | Prioritizing many initiatives or features by value vs. effort. |
| **Eisenhower** | Triaging a pile of tasks by urgency and importance. |
| **Pros / Cons** | Making a yes/no or two-way call where the reasoning matters. |
| **Expected Value** | Weighing uncertain outcomes with probabilities and payoffs. |
| **Cost–Benefit / ROI** | Deciding whether an investment is financially worth it. |
| **SWOT** | Assessing strengths, weaknesses, opportunities, and threats before a strategic move. |
| **Pre-mortem** | Surfacing what could go wrong before you commit to a plan. |

## How to use

Open the live link (or `index.html` locally) in any modern browser. Pick a framework or use **Start here** to get a recommendation. Load an example in any tool to see how it works. Your work saves automatically and can be exported to JSON or CSV.

## Run it locally

It's a single self-contained file — just open `index.html` in a browser. No build step, no dependencies.

## Host it yourself (GitHub Pages)

1. Create a public repository and upload `index.html` (and this README).
2. Go to **Settings → Pages → Build and deployment**.
3. Set **Source: Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/` within a minute.

## Privacy

All data stays in your browser's local storage on your own device. Nothing is uploaded or shared. Clearing your browser data clears your saved decisions.
